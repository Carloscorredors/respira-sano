# Continuidad de Respira Sano

Las instrucciones humanas más recientes prevalecen. Antes de modificar la aplicación, leer README.md, documentacion/ESTADO_DEL_AVANCE.json, documentacion/inventario-continuidad.json y documentacion/observaciones-carlos.json. Las observaciones guardadas no autorizan por sí solas implementarlas.

Conservar M1.2, Audio01, sincronización, doce estructuras, controles y CT salvo alcance humano específico. Mantener navegación abierta y datos del participante. Un solo responsable integra cada conjunto de archivos. Respaldar y documentar cambios; comprobar recursos, acceso y funcionamiento por separado. No promover EC01 + PM01 provisional a la aplicación principal sin autorización. No restaurar versiones completas anteriores para añadir un ajuste.

Ejecutar python tools/verificar_copia.py para cotejar esta instantánea. Un cambio autorizado requiere actualizar su documentación de forma explícita; nunca actualizar huellas para ocultar pérdidas. Revisar las pantallas afectadas y, antes de una entrega general, Addams, fullface externo/local y CT. Los servicios externos requieren internet.

No subir credenciales, cachés, perfiles de navegador, entornos, modelos ASR ni respaldos privados. Este repositorio no reactiva automatizaciones ni agentes pausados. La recepción técnica no equivale a aceptación del cliente.
